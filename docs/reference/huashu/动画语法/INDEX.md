# Huashu 动画语法完整卡

来源：Huashu Art Motion @ `a97c45018d46`，MIT。

| ID | 名称 | 一句话 | 完整卡 |
|---|---|---|---|
| `t1-3b1b` | 3Blue1Brown 式数学／概念可视化 | 黑底上只放「正在讲的那一个东西」，用平滑形变（Transform）把上一个概念直接变成下一个，颜色＝概念的名字，全片几乎不切。 | [t1_3b1b.md](./t1_3b1b.md) |
| `t2-keynote-ui` | 发布会式界面与渐变动效 | 一屏一件事，产品本身（截图、录屏、实物）当主角，名词和数字在口播说到时落定；字收紧，弹簧无回弹或轻回弹。 | [t2_keynote_ui.md](./t2_keynote_ui.md) |
| `t3-finance-chart` | 财经数据图表动画 | 先搭坐标系、再让数据「长」出来、最后只标一件事；一个颜色讲主角、其余变灰；数值永远诚实（柱从 0 起、单位和来源写在图上），动画只决定「怎么出现」，不改变「是多少」。 | [t3_finance_chart.md](./t3_finance_chart.md) |
| `y1` | Kurzgesagt 扁平科普 | 把一个抽象概念画成一个具体的物，放进能无限缩放的发光世界里，相机在尺度之间穿行；环境层（星、粒子）可以一直轻轻动，主体和信息在口播节点上发生变化，落定后停住。 | [y1_kurzgesagt.md](./y1_kurzgesagt.md) |
| `y2` | Vox 式拼贴解说 | 把论证摆在一张有真实材料的桌面上——剪报、照片、文件，相机像调查记者的眼睛在桌上移动；线和笔一顿一顿地画上去，证据感来自「这些东西是真的被放在这里的」。 | [y2_vox.md](./y2_vox.md) |
| `y3` | 白板手绘解说（RSA Animate 型） | 讲者说一句，手就在一张大白板上写一句、画一个图；相机跟着论证在板上移动，最后拉远，观众看到整场论证是一张图。 | [y3_whiteboard.md](./y3_whiteboard.md) |
| `y4` | 故事型简笔角色动画（YouTube storytime animation） | 口播是主角，画面是给口播配的「表情包」——角色在几个姿势之间快切（0.1 秒）然后定住，笑点靠切到反应大特写、并在那一下里闭嘴。 | [y4_storytime.md](./y4_storytime.md) |
| `y5` | 动态文字排版 / 信息图动效（kinetic typography） | 字就是演员——每个关键词踩一个重音砸进来，主词大到一眼读完，其余的字从「槽」里升起给耳朵对位；画面里永远只有一个焦点，镜头和底纹一直在动，字落定后不动。 | [y5_kinetic_type.md](./y5_kinetic_type.md) |
| `y6` | 讲解员式财经科普 | 一个卡通讲解员在纸面、图表和关键词之间串联信息。适合商业史、产品机制和带情绪反应的知识讲解。参考代码在`scripts/engine/reference_films/spacex/spacex_lin/`；这是第9种语法卡，目前没有独立参数化片段，也不附角色sprite。 | [y6_presenter_explainer.md](./y6_presenter_explainer.md) |
