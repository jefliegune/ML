## 完整版结构（约 2:00）

### 1. 开场钩子 0:00–0:10

直接使用当前预告。结尾从“机器学习”标题切进问题：“可它到底是怎么做到的？”

### 2. 规则 vs 例子 0:10–0:30

- 传统程序：人写规则，机器执行
- 机器学习：给出输入和答案，让机器自己找规律
- 画面：规则卡被划掉，样本卡片进入“学习传送带”
- 旁白重点：不是把答案写死，而是从数据中估计规律

### 3. 数据、特征、标签 0:30–0:55

- 一张猫图 = 像素矩阵 + 标签“猫”
- 特征不是“耳朵、胡须”这种人类语义，而是边缘、颜色、纹理等可计算模式
- 画面：图片拆成像素网格，再抽取出颜色块、轮廓线、局部纹理
- 旁白重点：机器看到的不是“猫”，而是一大堆数字

### 4. 模型开始预测 0:55–1:20

- 输入经过多层网络，输出“猫 / 非猫”的概率
- 第一次可能只给出 42%
- 画面：数据从左侧进入节点网络，右侧输出概率条
- 旁白重点：模型先大胆猜，再根据答案校准

### 5. 误差回传与参数更新 1:20–1:42

- 预测与标签比较，产生误差
- 误差反向传播，调整权重
- 重复成千上万次
- 画面：深色“训练室”，误差红色脉冲回传，权重数字逐帧变化
- 旁白重点：每一次犯错，都是一次微小修正

### 6. 泛化与过拟合 1:42–1:55

- 背题 vs 理解题：只记住训练样本，遇到新猫就失灵
- 画面：左边“背题机器”面对新图片卡住，右边“学会规律”的模型识别成功
- 旁白重点：真正重要的不是记住答案，而是对新样本也判断得准

### 7. 收束 1:55–2:00

- 三块结论卡：数据、模型、反馈
- 结束语：AI 不是魔法，它只是把“从经验中修正”这件事，做得非常快
- 画面回到荧光绿标题，加频道/系列标识与下期预告

## 制作拆解

1. 将完整旁白拆成 14–18 个短句，逐句生成音频并读取时长
2. 为每句建立字幕时间轴，句子级切换，关键词用荧光绿/珊瑚红高亮
3. 每个段落一个独立 Scene 组件，镜头内使用 spring + interpolate 驱动
4. 保持同一套卡片、阴影、点阵和顶栏系统，避免风格漂移
5. BGM 扩展为 2 分钟多段编曲：前奏、进入、训练段、揭示段、收尾
6. 关键转折使用 whoosh / riser / impact，数据出现使用轻 click / pop
7. 最终统一母带响度，检查字幕安全区与移动端可读性

## 品质检查清单

- 1080p 输出、30fps、H.264 + AAC
- 字幕距底部至少 40px，距左右至少 80px
- 主标题不小于 84px，重要辅助文字不小于 44px
- 旁白与字幕逐句对齐，关键词高亮不遮挡字形
- BGM 在旁白期间自动 duck，峰值不削波
- 所有画面元素使用 frame-based 动画，不使用 CSS transition
