# Huashu Fonts

This directory contains 45 WOFF font files imported from Huashu Art Motion.

- License: SIL Open Font License 1.1
- Copyright list: `LICENSES.md`
- License text: `OFL.txt`

Use `HuashuFonts` from `src/library/HuashuFonts.tsx` to register every family inside a Remotion composition. The original font URLs are stored in `src/library/huashu.json` and resolve through `staticFile()`.
